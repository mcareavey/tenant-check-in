# Tenant check-in form

A check-in inventory and schedule of condition that tenants fill in on their phone on moving-in day.

- Rate each item in the room and shared areas (Good, Fair, Poor, N/A) with notes
- Tick the safety checks and documents received
- Add photos and sign on screen
- Press Send to create a PDF, which the tenant sends to the landlord to countersign

Answers are saved in the tenant's browser until they send. Nothing is stored on a server.

The page is a single file, `index.html`, served with GitHub Pages.
